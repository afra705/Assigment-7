# 🛒 বাজার দর | BazarDor

### Know Today's Market Prices, Make Smarter Decisions

**BazarDor** is a web-based market price tracking application that helps users explore daily prices of essential products in Bangladesh. Users can compare prices across different markets, view price changes, and find the minimum, maximum, and average prices to make informed purchasing decisions.

## 🚀 Technologies Used

- **Next.js** — React framework for building the web application
- **React** — Component-based user interface
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Responsive styling and modern UI design
- **Better Auth** — User authentication and account management
- **REST API** — Fetching product and market price data

## ✨ Key Features

1. **📊 Daily Market Prices**  
   Browse updated prices of essential products, including rice, lentils, oil, vegetables, fish, meat, eggs, and spices.

2. **🏪 Market Price Comparison**  
   Compare minimum and maximum prices across different markets to identify affordable options.

3. **📈 Price Statistics**  
   View minimum, maximum, and average prices to understand market price differences.

4. **🔎 Product Categories and Details**  
   Explore products by category and view detailed price information for individual products.

5. **🔐 User Authentication and Profile Management**  
   Sign up, sign in, and manage your account profile securely.
